Puzzle Mama

A fresh set of three short puzzles every day, about eight minutes in all. Number Logic, Word Scramble and Memory Match, with a streak to keep you coming back. No account, no sign-up.

What it does

Three puzzles, one daily habit.

01

Number Logic

Fill a 6×6 grid so every row and column works out. A tap-and-number pad keeps it quick, with undo, erase and a hint when you are stuck.

02

Word Scramble

Unscramble five- and six-letter words using a category clue. Shuffle the letters, clear the row or ask for a hint.

03

Memory Match

Flip cards to find matching pairs. Every symbol has its own shape, so you never need colour to tell them apart.
